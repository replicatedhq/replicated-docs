Any other Kubernetes resources in the release (such as Kubernetes Deployments or Services) must include the `kots.io/installer-only: "true"` annotation. The Helm CLI never deploys these resources, but if any of them is missing the annotation, Helm CLI installations are not available for the release. See [Troubleshoot "Helm CLI install unavailable"](#helm-cli-unavailable) below.

The `kots.io/installer-only` annotation indicates that only the Replicated installers (Embedded Cluster, KOTS, and kURL) use this Kubernetes resource.

Example:
```yaml
apiVersion: v1
kind: Service
metadata:
  name: my-service
  annotations:
    kots.io/installer-only: "true"
```
