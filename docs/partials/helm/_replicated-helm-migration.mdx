You cannot switch a Helm chart in an existing installation from `useHelmInstall: false` to `useHelmInstall: true`.
If a user previously installed the Helm chart using `apiVersion: kots.io/v1beta1` and `useHelmInstall: false`, the installer displays the following error when a release changes the value of `useHelmInstall`: `deployment method for chart release <release_name> has changed`.

To move these installations to HelmChart v2 without reinstalling, see [Migrate from HelmChart v1 with useHelmInstall: false](/vendor/helm-v2-migrate#migrate-from-helmchart-v1-with-usehelminstall-false) in _Migrate existing installations to HelmChart v2_.
