Embedded Cluster v3 requires application preflight specs to use `troubleshoot.sh/v1beta3`, packaged inside a Helm chart or as a release-level file and rendered with Helm template syntax (not `repl{{ }}`). For chart-packaged examples, change the Preflight API version inside the Secret to `troubleshoot.sh/v1beta3` and keep the Secret wrapper.

:::note
These examples use `troubleshoot.sh/v1beta2` (supported by KOTS, kURL, and Embedded Cluster v2). KOTS v1.134.0 and later and Embedded Cluster v2 2.19.16 and later also support `troubleshoot.sh/v1beta3`.

The `v1beta3` requirement applies only to the Preflight custom resource. HostPreflight, SupportBundle, and Redactor specs continue to use `v1beta2` on all installer products, including Embedded Cluster v3. See [Application preflight specs must use v1beta3](/embedded-cluster/v3/embedded-v3-migrate#preflight-specs-must-use-v1beta3).
:::
