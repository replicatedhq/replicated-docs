:::note
The examples on this page use `v1beta2`. To use them with `v1beta3`, change the Preflight API version, keep any Secret wrapper, and replace `repl{{ }}` templates with Helm template syntax. For more information, see [Application preflight specs must use v1beta3](/embedded-cluster/v3/embedded-v3-migrate#preflight-specs-must-use-v1beta3) in _Upgrade from Embedded Cluster v2_.
:::
