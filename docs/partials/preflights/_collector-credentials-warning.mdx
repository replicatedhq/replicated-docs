:::important
The `mysql`, `postgres`, `mssql`, and `redis` collectors accept credentials only as a literal string in the `uri` field. Helm template functions and KOTS config options do not protect the credential. These functions and config options resolve to the live credential when the spec is rendered and deployed to the cluster, where a support bundle can collect the credential in plain text. The built-in redactors do not reliably mask these values.

Preflight checks run before your application is deployed, so a Secret created by your chart does not exist yet and cannot be referenced. Replicated recommends that you do not use these collectors in preflight checks. To check a database connection after the application is deployed, use a support bundle instead. For more information, see [Pass a credential to the pod](/vendor/support-bundle-examples#run-pod-credentials) in _Example support bundle specs_.
:::
