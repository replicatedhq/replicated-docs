:::note
Headless installation creates the cluster and deploys the application on the installation node before any other nodes can join. Using headless installation to create multi-node or high availability (HA) clusters from scripts or automation tools, such as Ansible, isn't supported. To create a multi-node or HA cluster, use the [Embedded Cluster UI](#install-using-the-embedded-cluster-ui), which pauses after the cluster is created so you can join nodes before the application deploys.
:::
