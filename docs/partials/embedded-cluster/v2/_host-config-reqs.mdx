Embedded Cluster configures the following kernel settings itself at the start of installation, and when a node joins the cluster, before the host preflight checks run. The preflight checks then verify the result and report anything that could not be applied. You do not need to set these values in advance. This section describes what Embedded Cluster changes on the host, which is often needed for security review.

Every change in this section is best effort. If one cannot be applied, installation continues and the host preflight checks report the problem. Embedded Cluster uses the `modprobe` and `sysctl` commands to make these changes. If either command is missing from the host, Embedded Cluster skips the related settings.

**Kernel modules.** Written to `/etc/modules-load.d/99-embedded-cluster.conf` so that they persist across reboots, and loaded immediately if the host kernel provides them:

`overlay`, `ip_tables`, `nf_tables`, `nft_compat`, `br_netfilter`, and `nf_conntrack`

**Network parameters.** Written to `/etc/sysctl.d/99-embedded-cluster.conf` and applied:

| Parameter | Value |
|---|---|
| `net.ipv4.ip_forward` | `1` |
| `net.ipv4.conf.all.forwarding` | `1` |
| `net.ipv4.conf.default.forwarding` | `1` |
| `net.ipv6.conf.all.forwarding` | `1` |
| `net.ipv6.conf.default.forwarding` | `1` |
| `net.bridge.bridge-nf-call-iptables` | `1` |
| `net.bridge.bridge-nf-call-ip6tables` | `1` |
| `net.ipv4.conf.all.arp_filter` | `0` |
| `net.ipv4.conf.default.arp_filter` | `0` |
| `net.ipv4.conf.all.arp_ignore` | `0` |
| `net.ipv4.conf.default.arp_ignore` | `0` |
| `net.ipv4.conf.all.rp_filter` | `2` |
| `net.ipv4.conf.default.rp_filter` | `2` |

Reverse path filtering is set to loose mode. Strict mode, which is the value `1`, drops pod traffic.

**Resource limits.** Written to `/etc/sysctl.d/99-dynamic-embedded-cluster.conf`, and only for values that are lower on the host than the following minimums:

| Parameter | Minimum value |
|---|---|
| `fs.inotify.max_user_instances` | `1024` |
| `fs.inotify.max_user_watches` | `65536` |
