# node join

This topic describes the options available with the Embedded Cluster `node join` command.

## Usage

```bash
sudo ./<app-slug> node join [flags]
```

## Flags

To check a node without joining it, run `join run-preflights` from its extracted join bundle. For more information about checking a node before joining, see [Check a node before joining](embedded-host-preflights#check-a-node-before-joining) in _Run host preflight checks without installing_.
